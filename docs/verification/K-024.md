# K-024 — Flujo del MVP simplificado

Verificado el 2026-10-31 con datos y puertos aislados en Ubuntu 24.04. Se reutilizan las 106 pruebas API y tres de selección ya correctas en K-032; no se repiten suites retiradas ni se ejecuta IA.

## Checklist reproducido

- [x] Dos registros de proyecto, asociados a carpetas independientes. Asociar/abrir el segundo no crea `.konsora` automáticamente. Cambiar de proyecto reinicia la selección.
- [x] `tasks.json` generado fuera de Konsora; detección de A/B/C. Selección de A por teclado y C con casilla. Filtro de texto conserva ambas e indica una oculta.
- [x] Contexto explícito incluido; B es dependencia de C fuera de selección y aparece solo como referencia. Título/descripción/trabajo de B ausentes del prompt.
- [x] Copia al portapapeles exactamente igual a la vista previa. Escritura denegada simulada: revalidación, selección completa y acción Ctrl+C. La copia nativa real fue comprobada con GTK en K-032.
- [x] Exportación opcional exacta; segundo guardado al mismo nombre rechazado y contenido conservado. Copiar/guardar no modifica el archivo de tareas.
- [x] Cambio externo sin incrementar `version` invalida el prompt y deshabilita su copia hasta regenerar.
- [x] Edición concurrente: guardar devuelve conflicto, conserva el borrador y no pisa el archivo externo; recargar detalle descarta explícitamente el borrador. Escape cierra el detalle.
- [x] JSON inválido y archivo desaparecido: última lectura conservada, escrituras/copia deshabilitadas. Restauración del archivo recupera el tablero.
- [x] Recargar la aplicación recupera tareas guardadas. API: reinicio del registro, migración SQL a archivos sin alterar filas/IDs/intentos/actividad y reconstrucción desde carpeta copiada con una base nueva, cubiertos por `test_file_tasks.py` y `test_workspaces.py`.
- [x] Sin navegación de chats, cuentas ni botones/rutas de ejecución/proveedores. El recorrido genera únicamente peticiones del MVP. Las pruebas de prompt prohíben crear procesos externos; no se requieren CLIs/sesiones de IA.
- [x] Cliente no autenticado del proxy web recibe 401; origen externo incluso autenticado recibe 403. Clave ausente de los logs capturados.

Tipos/build web y nativo release correctos en K-032. Recorrido de carpeta → selector nativo → tablero → selección → copia → cierre comprobado en Tauri/WebKitGTK, con backend integrado. El recorrido ampliado de errores/filtros se automatizó en Chrome mediante el proxy autenticado de desarrollo; no se presenta como una segunda prueba nativa.
