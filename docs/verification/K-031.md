# K-031 — MVP de visualizar y copiar prompts

Completada, 2026-10-30. Alcance vigente: carpeta → tareas de archivos → tablero → selección → prompt → copiar/pegar fuera de Konsora.

Retirados componentes/clientes de chats y conversaciones, selector/catálogo de proveedor/modelo, comprobación de Codex, simuladores, rutas HTTP de conversación/inferencia y el código que lanza procesos CLI. La fábrica de la API ya no configura proveedores ni mantiene conversaciones activas. El tablero abre directamente; la carpeta y metadatos quedan en un desplegable. No existe botón de ejecución, ni siquiera deshabilitado.

Se mantienen generación/copia/exportación opcional de prompts, operaciones manuales de tareas y lectura de historial compatible. Los registros de intentos importados no representan procesos supervisados por el MVP. Las utilidades compartidas de texto y validación de proyecto se separan de los módulos retirados.

Las tablas/mensajes/debates históricos y las migraciones permanecen intactos. Las rutas retiradas devuelven 404, no se ofrecen como API de archivo histórico y no se convierten sus datos en tareas. El borrado local explícitamente confirmado conserva su comportamiento anterior y no elimina archivos de trabajo.

Se actualizan `AGENTS.md`, `TASKS.md`, `README.md`, guía técnica y formato. El plan de ejecución integrada anterior se archiva, sin perder sus identificadores/evidencia. K-018 y K-022 quedan canceladas; lanzadores, modelos, varios agentes, colas y supervisión son posteriores al MVP. La seguridad local previa a distribución se separa como K-032.

## Repetir

Iniciar servicio y escritorio según [desarrollo](../desarrollo.md). Asociar una carpeta con `tasks.json`, seleccionar varias tareas, filtrar, preparar y copiar el prompt. No debe aparecer ningún chat, selector de proveedor/modelo o botón de ejecución. El estado inferior solo comprueba el servicio local, nunca una herramienta de IA.
