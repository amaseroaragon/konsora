# K-017C — Prompts desde archivos seleccionados

Completada, 2026-10-30. Vista previa, copia revalidada y guardado explícito de un prompt con las tareas seleccionadas y el contexto escrito por la persona. Sin login ni consultas a modelos; la ejecución permanece deshabilitada.

La vista identifica carpeta, archivo y revisión, tareas/huellas/orden y bloqueos. No se añaden dependencias ni contenido de tareas no seleccionadas. Cambios de archivo, selección o contexto invalidan la vista; copiar y guardar releen el origen y comprueban su huella. Se bloquea la selección mientras se prepara/copia/guarda para evitar cambios durante la operación. Un archivo copiado previamente sigue siendo una instantánea, nunca una autorización vigente.

Guardado exclusivo en `.konsora/prompts/<nombre>.md`, con nombre elegido por la persona, descriptores sin symlinks, bloqueo cooperativo, comprobación final de revisión y escritura atómica sin reemplazar destinos. No modifica el documento de tareas. Copia mediante portapapeles estándar; cuando no está disponible, selecciona el texto revalidado para Ctrl+C.

Pruebas focalizadas:

- `test_task_prompts.py`: **8 correctas**. Selección A/C con trabajo de B excluido, dependencia externa como referencia, contexto explícito y ausencia de lectura implícita de otros archivos; sin proveedores configurados ni procesos permitidos. Cambios sin aumento de versión y cambio de contexto rechazan una vista previa anterior. Exportación con contenido exacto y origen intacto, rechazo de sobrescritura, rutas relativas/absolutas y extensiones incorrectas, symlink del directorio de salida y selección repetida/vacía/inexistente.
- Un recorrido UI sobre el build de producción: A y C seleccionadas con C oculta por filtro; B solo aparece como bloqueo. Vista previa, copia al portapapeles, fallback Ctrl+C comprobando selección del texto, exportación y rechazo de sobrescritura. Edición externa sin cambiar versión y cambios de contexto inhabilitan copia/guardado hasta regenerar. Cambiar de proyecto reinicia selección y elimina el prompt anterior. Sin errores JavaScript ni peticiones de agentes.
- Capturas a 1100 × 850 y 640 × 640 revisadas, sin desbordamiento horizontal de página.
- `npm run build:desktop`: tipos y builds web/nativo correctos. No se repiten las suites de tareas/almacenamiento ya comprobadas en K-017A/B.
- `git diff --check`: correcto.

El prompt no supervisa una herramienta externa ni acredita sus resultados. Los cambios en los archivos se detectan para revisión; la ejecución/aprobación integrada se implementará en K-019–K-021.
