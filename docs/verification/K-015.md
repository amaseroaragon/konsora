# K-015 — Carpetas locales por proyecto

Fecha: 2026-10-30. Completada.

Migración v4 aditiva con `workspace_path` nullable. Los proyectos anteriores siguen abriéndose sin inventar rutas; se conservan chats, mensajes y registros históricos. API tipada para asociar/cambiar/desvincular, guardando la ruta absoluta canónica. El estado de la carpeta se calcula al consultar el proyecto, sin cambiar su asociación por errores del sistema de archivos.

La validación comprueba existencia, tipo directorio, enlaces, lectura/escritura/travesía y rechaza raíces amplias, directorio personal completo y ubicaciones del sistema/configuración. Un enlace aceptado se guarda por su destino; reemplazar la ruta guardada por un enlace a otro destino produce estado inseguro. No se escriben archivos de prueba ni se leen contenidos. Esta comprobación no sustituye al aislamiento y la revalidación previa a la futura ejecución.

La UI permite elegir y guardar explícitamente, comprobar, cambiar y desvincular; muestra estados y errores recuperables. El diálogo de borrado explica que conserva la carpeta y sus archivos. Se usa el [plugin oficial Tauri Dialog](https://v2.tauri.app/plugin/dialog/) 2.8.4, con permiso exclusivo `dialog:allow-open` en la ventana principal. En desarrollo web se permite introducir una ruta absoluta.
