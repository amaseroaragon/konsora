# K-014 — Retirada funcional del debate

Fecha: 2026-10-30. Completada.

Retirados navegación, componentes, cliente HTTP, estilos, servicio, rutas y simuladores de participantes. El proyecto abre directamente sus conversaciones y ya no muestra Claude como segundo participante. La guía de desarrollo referencia el backlog vigente y describe la conservación del historial.

Las migraciones v1–v3 permanecen intactas. No se borran ni convierten registros históricos ni se recuperan sus estados al arrancar. El borrado explícito y confirmado de un proyecto conserva su cascada anterior sobre todo el historial local, explicada en el diálogo.

## Comprobaciones realizadas

- `npm run check`: tipos y build web correctos; **115 pruebas API correctas**. Se conserva la regresión de proyectos, chats, errores, persistencia y procesos CLI, incluidos límites, cancelación y descendientes. Sigue el aviso previo de deprecación HTTPX/Starlette.
- Cuatro pruebas específicas sustituyen al contrato de debates retirado: apertura de una base v3 tras reinicios con igualdad exacta de todas sus filas, rutas antiguas 404 y ausentes de OpenAPI, continuación de un chat antiguo sin alterar debates/propuestas y cascada únicamente con borrado confirmado. La base de prueba incluye una propuesta completada y otra en curso para detectar cualquier modificación automática de su estado.
- `npm run build:desktop`: binario nativo compilado correctamente.
- Comprobación Ubuntu mediante AT-SPI sobre el binario de producción: abrir proyecto, abrir chat persistido, leer respuesta, actualizar historial y cerrar correctamente; ausencia de Debate y Claude en la interfaz accesible. API y SQLite de prueba aisladas bajo `.tools/`, solo conector simulado, sin invocar Codex real ni consumir cuota.
- Revisión React: importación directa de conversaciones, clave por proyecto que conserva el aislamiento al cambiar, confirmación de borrado accesible y sin nuevos efectos, estados ni dependencias.
- `git diff --check`: correcto.
