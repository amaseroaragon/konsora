# K-001 — Verificación de la base de Konsora

Fecha: 2026-10-28. Entorno: Ubuntu 24.04.4, sesión gráfica Wayland, Node 22.22.2, Python 3.12.3, Rust 1.99.1 y WebKitGTK 2.52.6.

Flujo comprobado: abrir Konsora → solicitar `GET /health` al backend local → validar el contrato → mostrar el estado de conexión y permitir reintentar.

## Flujo real en Ubuntu

Se ejecutaron los comandos de desarrollo documentados y se inspeccionó la ventana nativa mediante AT-SPI. La revisión visual adicional se hizo con Chrome, sin incorporar herramientas de navegador a las dependencias de la aplicación.

| Límite del flujo | Evidencia |
| --- | --- |
| Arranque de la API | Uvicorn inicia con `Application startup complete`. |
| Escucha local | `ss` muestra exclusivamente `127.0.0.1:8000`. |
| Contrato real | `curl --fail http://127.0.0.1:8000/health` devuelve `{"status":"ok","service":"konsora-api"}`. |
| Ventana nativa | `npm run dev:desktop` compila y abre una ventana con título Konsora. |
| Binario de producción | Se abre `target/release/konsora-desktop` con Vite detenido (puerto 1420 libre); la pantalla muestra **API conectada**. |
| Respuesta → interfaz | La ventana real muestra **API conectada**. |
| Error de red | Tras detener la API, pulsar **Comprobar conexión** muestra **Sin conexión con la API** y la indicación para arrancar el backend. |
| Recuperación | Reiniciar la API y pulsar el botón restaura **API conectada** en la misma ventana. |
| Cierre | El botón de cierre de la ventana termina el proceso del escritorio con código 0 y libera el puerto de Vite. |
| Revisión web | Sin errores JavaScript, de consola ni recursos HTTP fallidos. Sin desbordamiento horizontal a 1100 × 820 ni a 640 × 600. |

## Decisiones y límites

- Backend y escritorio se ejecutan en procesos independientes durante desarrollo, conforme al backlog. La integración del ciclo de vida y el instalador corresponden a K-012.
- No hay permisos de sistema habilitados para la ventana ni dependencias de interfaz adicionales. La CSP limita las conexiones al backend local y al servidor de desarrollo.
- Esta tarea no añade persistencia, modelos, credenciales ni ejecución de agentes. La próxima tarea es K-002.
- La instalación de bibliotecas de Ubuntu se completó con los índices oficiales. `apt update` también detectó errores previos de firma o disponibilidad en repositorios externos de la máquina; su configuración no se modificó.
