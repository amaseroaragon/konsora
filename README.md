# Konsora

Konsora es una aplicación de escritorio local-first para Ubuntu.
Su objetivo es organizar tareas y resultados que pertenecen a los archivos de cada proyecto.
Ofrece un tablero para seleccionar tareas y preparar su ejecución con IA.
Una IA externa puede crear las tareas; Konsora detecta los cambios en sus archivos.
La ejecución integrada prevista utiliza una única cuenta y proveedor, empezando por Codex CLI con ChatGPT.
Las tareas y resultados viajan con la carpeta y pueden versionarse con Git.
Utiliza la suscripción del usuario, sin integrar APIs de pago.
El tablero y los prompts desde archivos están disponibles; la ejecución integrada sigue en desarrollo.
