# Konsora

Konsora es una aplicación de escritorio local-first para Ubuntu.
Visualiza las tareas que viven en los archivos de cada proyecto.
Permite seleccionar varias y generar un prompt para copiar y pegar.
Las tareas pueden ser creadas o modificadas por una IA externa o por la persona.
El tablero detecta los cambios y muestra estados y dependencias.
Los prompts también pueden guardarse en la carpeta sin sobrescribir archivos.
No requiere CLIs de IA ni cuentas de proveedores y no ejecuta agentes.
El lanzamiento de herramientas y el uso de varios agentes quedan para versiones posteriores.
