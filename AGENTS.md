# Konsora — instrucciones para agentes

Las instrucciones de este repositorio están en [CLAUDE.md](CLAUDE.md) y se aplican igual a cualquier agente (Codex, Claude Code u otros). Léelo entero antes de empezar.

Lo esencial: el estado actual y el siguiente hito están en `CLAUDE.md`. El diseño está en `docs/` (`vision.md`, `arquitectura.md`, `esquema-tareas.md` y `roadmap.md`). Sobre el plan tienes permisos de agente: puedes crear tareas, empezarlas, anotar, preguntar y terminarlas con un resumen (`finish` las deja en `done`), pero no reabrirlas ni cambiar lo ya terminado, que es cosa del humano. Haz commits locales pequeños en inglés y nunca hagas push.
